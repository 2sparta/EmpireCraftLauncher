# Empirecraft Launcher 0.1.2 · beta

Власний легкий лаунчер Empirecraft для Minecraft 1.20.1 / Forge 47.4.23.
Сервер: **p2.foxter.top:25628**.

## Завантаження

- [Windows x64 — ZIP](https://github.com/2sparta/EmpireCraftLauncher/raw/refs/heads/main/downloads/Empirecraft-Launcher-0.1.2-Windows-x64.zip)
- [Linux x64 — ZIP](https://github.com/2sparta/EmpireCraftLauncher/raw/refs/heads/main/downloads/Empirecraft-Launcher-0.1.2-Linux-x64.zip) — локальна збірка Debian 13, старіші дистрибутиви не перевірені.
- Контрольні суми розміщені поряд із ZIP у [downloads](downloads).

Розпакуй **усю папку**, запусти `Empirecraft.exe`, обери профіль і введи нік. Лаунчер встановить Java 17, Forge та перевірену клієнтську збірку. Пароль серверної авторизації вводиться тільки у грі. GitHub-токен не потрібен. Початкове встановлення потребує інтернету та кількох ГБ вільного диска.

## Профілі

| | Potato | Balanced | High |
|---|---|---|---|
| Дальність | 5 чанків | 8 чанків | 12 чанків |
| Ліміт FPS | 60 | 90 | 120 |
| Частинки / ефекти | мінімум, ефекти LSO й візуальний дощ вимкнені | помірні | детальні |
| Звукова фізика / Dynamic FPS | відсутні | є | є |
| Oculus | відсутній | відсутній | є, шейдери початково вимкнені |

RAM, дальність, ліміт FPS і зменшені ефекти налаштовуються окремо. Ігрові моди й індикатори виживання залишаються у всіх профілях. Лаунчер перевіряє мінімум 6 ГБ фізичної RAM; для збірки бажано 8 ГБ або більше. Potato автоматично виділяє до 4 ГБ Java, залишаючи пам’ять ОС. Ліміт FPS не є обіцянкою продуктивності.

Кожний профіль має окрему папку. Керування, мова, карти й скриншоти зберігаються. «Діагностика» показує пам’ять і паузи Java; локально записуються CPU, RAM, swap та дисковий ввід/вивід. Телеметрія не надсилається. Недоступні лічильники Windows пропускаються й не блокують гру.

## Оновлення й безпека

Публічний [канал](channel/stable.json) підписаний Ed25519. Кожний файл закріплений SHA-256 і незмінним Git commit. Лаунчер перевіряє адреси HTTPS, шляхи, розміри, підписи, строк дії та відкат версій. Встановлення транзакційне, є перевірка/відновлення файлів. Оновлення збірки перевіряються перед запуском; EXE оновлюється окремо.

Клієнтське меню запускає підключення до Empirecraft, а власний аддон блокує звичайні спроби підключення до іншої адреси. Це обмеження нашого клієнта; власник ПК може змінити його файли. Серверна авторизація залишається окремим захистом доступу.

У цьому репозиторії тільки клієнтська збірка та джерела лаунчера. Приватні ключі, серверні папки, світи й дані гравців не публікуються. [Налаштування наступних автоматичних релізів](launcher/ADMIN-SETUP.md) потребує одноразового додавання ключів у GitHub Secrets власником.

## Стан перевірки

Пройдено автоматичні перевірки підписів, безпечних шляхів, оновлення та профілів. 47 перевірок, GUI та пакування успішно пройшли у Windows/Linux GitHub Actions. Чисте встановлення Java 17 / Forge та всіх трьох профілів із публічного каналу перевірено. Власний Windows EXE також запускався через Wine. Деталі — [TESTING.md](launcher/TESTING.md).

Фізична Windows, повний графічний запуск Minecraft, вхід на сервер, шейдери з Create та FPS на слабкому ноутбуці ще потребують приймального тесту. Збірка EXE поки без Authenticode-підпису; не відключай антивірус.

## Розробка

Python 3.12 з Tk: `python -m pip install -r launcher/requirements-build.txt`, потім `python launcher/run.py`.
Тести: `python -m pytest launcher/tests -q`.
